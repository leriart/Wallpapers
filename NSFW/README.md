# NSFW

Contenido para adultos — **oculto por defecto** en la página.

- El clasificador automático manda aquí todo lo que detecte como
  `questionable`, `explicit` o `sensitive` (vía el rating de la API).
- En la página web no aparece en la galería, búsquedas, ni contadores.
- Para verlo: **Filters → NSFW** (opciones avanzadas). La preferencia se
  recuerda en tu navegador.
- También se excluye del README del repo.
