# Por organizar

Sube aquí los wallpapers que quieras agregar a la colección (imágenes o videos).

Al hacer push (o subirlos desde la web de GitHub), el pipeline automático:

1. **Clasifica** cada archivo y lo mueve a su carpeta correcta
   (Anime, Landscape, Dark, Space, ...)
2. **Elimina duplicados** (si el archivo ya existe en la colección)
3. **Genera tags** de personajes/series y actualiza el buscador
4. **Publica** la página automáticamente

No necesitas hacer nada más que subir los archivos aquí. 🚀
